## 控制与可信度，待评审

- [ ] 区分 Agent、模型、工具、调度器和 Worker 的责任。
- [ ] 授权绑定具体版本、目标和动作，变更后失效。
- [ ] 区分取消请求、停止完成和副作用回退。
- [ ] 中断结果未知时先核查，不盲目重试写入。
- [ ] 区分任务完成、测试通过和用户验收。
- [ ] Token、成本和并行耗时口径明确，无父子重复计费。
- [ ] 成本不可得、调用缺失和未经验证能力明确标记。
- [ ] 凭证与敏感内容不默认采集，不展示模型内部思维链。
- [ ] 普通审计日志不被宣传为防篡改记录。
- [ ] 开启共享访问前具备身份、项目隔离和明确的审批责任。
- [ ] 执行、验证、人工验收分开显示；不把模型宣称完成当作测试通过。
- [ ] 适配器声明实际可用的暂停、隔离、委派和计量能力，不默认所有运行时一致。
