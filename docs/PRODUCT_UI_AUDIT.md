## 结论

当前 mybot 已有较完整的页面骨架，但仍处于“多页面切片集合”，还不是一套完全统一
的研发工作台。最需要优化的不是继续添加页面，而是：

1. 统一全局壳层、页头、工具栏、状态和空态。
2. 统一任务/Run/项目的事实投影和计数口径。
3. 统一列表查询、分页、详情预览和移动端行为。
4. 统一配置表单的验证、保存、测试、撤销事实。
5. 把高级 Astryx 控件接入真实字段合同，而不是只换视觉。

**决策建议：保持 React 19 + Astryx 0.7.13 + Python/FastAPI，不重写后端，
不引入第二套组件库；先统一产品模式和真实工作闭环，再增加高级控件。**

本轮范围不是全仓库安全审计：主 Agent 阅读业务路由/投影/主题/样式并只读预览，
两名 Agent 分别审查 Run/表单合同和交互/共享组件。结果区分源码发现、浏览器证据和
后续提案。未读取兄弟项目凭证/数据库，未发真实模型请求或改变权限。

## 统一设计目标

### 壳层

- 顶栏只负责全局导航、快速查找、同步状态、主题/语言和账户。
- 页面内部统一：上下文/标题 → 主操作 → 查询或条件 → 结果工具栏 → 结果/详情。
- 页面不重复实现自己的页头、按钮间距、错误条和空态。
- 桌面侧栏、上下文范围和移动抽屉使用同一状态来源。

### 查询与列表

- 顶部 `快速查找` 与页面列表搜索严格分离。
- 列表搜索采用一行查询带；草稿和已提交值分开。
- Basic/JQL、条件筛选、排序、分页和视图写入同一 URL 合同。
- 表格、卡片、看板、详情使用同一投影；不在不同页面重复计算历史 Run。
- ID、摘要、状态、项目、时间等列有稳定宽度；长文本截断，详情显示完整内容。

### 状态与事实

- `queued/running/paused/failed/succeeded/canceled` 是执行状态，不等于人工验收。
- 成本、认证、读取权限、连接可达和执行能力分别显示，unknown 不填零。
- 错误、403、空结果、无权限、未配置、撤销和未验收不能共用一个空态。
- 历史失败不能覆盖当前已恢复任务；统计必须注明是任务、Run 还是调用。

### 表单与配置

- 保存配置、测试连接、默认选择、能力验证、执行完成、撤销分别反馈。
- 表单失败保留输入；依赖字段变化撤销旧 consent；重复提交有 busy/idempotency。
- 模型/后端页面优先用紧凑设置行和状态分组，不使用大卡片堆叠。

### Astryx 高级能力路线

保持 Astryx 组件体系和版本不变，按真实合同逐步采用。下表是安装包的本地类型/
导出检查，不是上游最新版本推荐，也不代表全部高级组件已接入业务：

1. 已使用：`TextInput`、`Selector`、`SegmentedControl`、`Button`、`Dialog`、
   `Table`、`Badge`、`Skeleton`、`CommandPalette`、`AvatarGroup`。
2. 下一阶段：`InputGroup` 统一查询带几何；`Pagination` 支持实际受控 page/pageSize、
   页号/计数/输入变体；`Drawer`/`BottomSheet` 统一手机详情与筛选。先做项目包装和
   状态合同，不为高级而强行替换已验证组件。
3. 字段合同成立后：`PowerSearch` 做 token 条件搜索；`ComplexSelector` 做复杂
   条件编辑；`MultiSelector` 做多项目/多状态；不能提前伪造完整 JQL。
4. Run 观测成熟后：`Collapsible`、`ScrollableArea`、`Resizable`、`TabList`、
   `MoreMenu` 统一长记录、面板和动作。
5. `Table` 安装包已导出列配置/列宽/固定列/选择/分组/树/行虚拟化等插件：
   `useTableColumnSettings`、`useTableColumnResize`、`useTableStickyColumns`、
   `useTableSelection`、`useTableGroupedRows`、`useTableRowsVirtualization`。
   列配置/调整可先做；分组须定义任务/Run 单位；批量选择不附带批量执行权限；
   虚拟化先测真实大列表，不能与全量 API 读取混为一谈。

组件层拟形成 `AppPageHeader`、`AppQueryToolbar`、`AppResultState`、`AppInspector`、
`AppFormSection` 五类共享组合，均基于 Astryx；这是待实现的设计，不是现有模块。
Generic 组件不包含 Run/模型授权逻辑，Task/Run 详情仍留在领域组件。

核查路径：安装包 `dist/{InputGroup,PowerSearch,ComplexSelector,Pagination}/` 的
`.d.ts` 和 `dist/Table/index.d.ts`；未安装新包/升级主题/复制其他项目运行时。
