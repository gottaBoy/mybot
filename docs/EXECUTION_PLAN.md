## 后续 POC

### P0-A：调研与方案

目标 -> 计划 -> 按需分工 -> 来源与分歧 -> 可编辑方案。

验收：不依赖仓库、GPU 和部署系统；结论可追溯；能处理模型失败、预算耗尽和取消。

### P0-B：代码修改与测试

限定仓库 -> 修改计划 -> 隔离实现 -> Diff -> 真实测试与审查 -> 用户决定是否应用。

验收：未授权不写入；主工作区不自动合并；测试未运行不显示通过；中断后先核查副作用。

### P0-C：追踪验证

对以上运行检查：所有模型/工具调用有归属；重试不覆盖历史；图与调用表一致；断线不丢状态；父子成本不重复计算；审批不能被旧版本复用。
