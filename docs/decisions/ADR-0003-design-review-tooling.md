# ADR-0003：低保真评审使用独立浏览器工具

- 日期：2026-11-02
- 状态：本轮设计验证选择；不是正式产品的浏览器工具选型

## 背景

用户询问是否需要 egolite，并要求提交代码、记录关键进度。

本轮将其理解为 Citro Labs 的 ego(lite)，官方仓库为 `citrolabs/ego-lite`。如用户指的是同名其他项目，需要另行确认。

## 公开资料与边界

2026-11-02 查阅官方仓库 README：ego(lite) 为 Agent 提供浏览器交互与人在环接管能力，可使用浏览器上下文；不是研发工作台的任务编排、调用审计或成果管理替代品。

官方仓库当时列出 macOS、Windows，Linux 处于路线图。没有在本机安装或运行，因此不作兼容性、安全或可靠性验收结论。

```text
https://github.com/citrolabs/ego-lite
```

## 决定

1. 本轮静态设计不引入 ego(lite)。
2. 用 Playwright 和独立 Chrome 检查本地设计文件，不使用个人浏览器登录态。
3. 不接账号、不发模型请求、不执行真实项目或部署动作。
4. 未来真实浏览器工作流再比较 ego(lite) 等候选，重点检查平台支持、会话隔离、权限、取消、审计与人工接管。
5. 本轮工具选择不决定工作台的业务架构。

## 记录

用户已明确要求本轮结果提交 Git。提交范围为当前项目的设计、研究、交接记录、静态稿与验证证据；不推送远端，不修改其他项目。
