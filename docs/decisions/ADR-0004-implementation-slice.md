# ADR-0004：开始实现只读研发调研闭环

- 日期：2026-11-04
- 状态：用户已授权开始实现；本轮范围由实现记录约束
- 修订：此前“只做静态设计、不写业务代码”的阶段限制

## 决策

1. 面向研发团队、单人试点的定位不变。
2. 静态设计稿保留。真实应用独立位于 `workbench/`、`web/`。
3. 先实现只读研发调研：项目、模型配置、任务、持久运行、有限研究分工、调用追踪、成果与审查。
4. 使用一个 FastAPI 进程、SQLite 和一个后台 Worker；暂不引入集群、Redis 或多套 Harness。
5. 这是受限的固定阶段编排，不宣称已接入 DeepSeek Harness、OpenHands、Shell 或任意自主工具 Agent。
6. 首版模型通过 OpenAI-compatible Chat Completions 适配器调用，不自动重试或跨 Provider 回退。
7. 真实模型仅在用户点击“测试连接”或确认资料后开始运行时调用；本轮验收使用测试 Provider，不消耗付费额度。
8. 首版界面是响应式 Web，Mac/Linux/Android/iPhone 的目标使用方式均为浏览器。
9. 远程访问前需要令牌、明确 Host 白名单与 HTTPS；默认仅监听本机，未上线团队共享。

## 不变边界

- 不读取其他项目 `.env`、数据库或凭证。
- 只读取本项目配置的服务器工作区内，用户明确选择并确认的源码文本快照。
- 不提供代码写入、Shell、浏览器工具或部署权限。
- 模型宣布完成、测试验证和用户接受分别记录。
- 不让静态样例混入真实应用数据。

## 恢复与控制

暂停在阶段边界生效，当前阶段的只读调用收敛后暂停。取消会请求中断本机 HTTP 调用，但不能保证 Provider 不再处理或收费。

服务重启后，运行中任务标记中断，已发出的模型请求用量可能未知；不自动回放。手动继续需确认可能再次产生费用。完整阶段输出可复用，调用总上限仍对同一 Run 的所有尝试生效。

## 后续

真实 Provider 兼容性、Safari/设备真机、生产鉴权和跨主机持久任务仍需专项验证。代码沙箱与写入门禁作为独立后续阶段，不在只读闭环中偷渡实现。
