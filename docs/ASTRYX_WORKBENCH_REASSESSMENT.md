# mybot 项目复核与 Astryx 业务迁移

日期：2026-11-13。依据：当前仓库、ADR-0005/0006、已安装 Astryx 0.7.13
类型及实现、本地隔离浏览器运行。本文覆盖当前切片，不替代
[119 项工作台账](WORK_ITEMS.md)，也不代表整体视觉已获用户接受。

## 1. 结论

**保留现有业务后端，用 Astryx 实现真实任务工作台；不再把模板 Playground
作为主要交付，不为换 UI 重写 Rust 服务或再叠一套编排框架。**

目标仍是研发团队的多端 Agent 工作空间，先由一个开发者验证。Astryx 解决
控件、主题、表单及弹层基础，不提供 Cindy 的设备接力、OpenMausBot 的长期会话、
执行器隔离或任意工作流编排。这些能力必须独立实现、验证。

## 2. 当前事实

| 层次 | 已有能力 | 本轮之前的主要问题 |
| --- | --- | --- |
| 产品域 | Project、Task、Run、Agent、Call、Artifact、Event | 固定研究流程，尚非长期 Agent/任意 DAG |
| 后端 | FastAPI、SQLite、单 Worker、快照确认、三阶段 Harness、角色路由、预算、控制、关联重试 | 执行权限与工具 ceiling、真实 Provider 覆盖仍有限 |
| 旧版 `web/` | 可运行的项目/模型/任务/运行/重试/缓存页面 | 原生 JS 与 React 并存，体验不一致 |
| React 产品页 | Bootstrap 摘要与只读 Chat | 部分导航回落首页，主要按钮无动作，首页偏迁移说明 |
| Astryx 工具 | 58 模板、Monaco、主题编辑、隔离预览、属性编辑 | 工具完成度不等于业务工作台完成度；通用依赖分组拖累产品首屏 |
| 外部后端 | 配置、显式健康检查、撤销、离线只读合同 | 生产 transcript 同步默认关闭，不能宣称已接通 OpenMausBot |
| 多端与扩展 | 响应式浏览器、后端适配端口 | 未验收真机接续、设备授权、飞书/微信/钉钉/语雀/邮箱连接器 |

因此优先级是打通现成工作闭环及可信状态，而非继续增加无业务动作的页面。

## 3. 本轮实现

业务入口为 `frontend/src/workbench/`：

```text
App                          模板/预览与业务路由隔离
  Workbench                  认证、导航、项目/运行列表、模型和后端配置
    WorkbenchForm            项目/任务/模型/连接及运行确认
    RunWorkspace (lazy)      阶段图、Agent、调用、成果、审计、暂停/取消
  components/ui              项目自有 Astryx 适配层
  api + state                API 边界、稳定状态码与纯读模型
        |
     现有 /api               不另建数据库或执行编排器
```

- 任务优先的列表、项目筛选、状态筛选、检索、分页展开和项目详情。
- 创建项目/任务后真实保存；显式选文件，预览实际快照，再确认启动。
- 规划/研究/汇总独立选模型，可分配调用、并行、时限与输出资源。
- 模型配置支持本机推理地址快捷填写、本地 Codex 配置启用、默认模型选择。
  保存不测试；连接测试另需确认。不会读取或复制本机凭证。
- 后端配置、显式健康检查和撤销；可达仍不等于认证或读取权限已验证。
- Run 阶段状态、Agent 输出、逐调用 Token/未知、诊断、审计与关联重试历史。
- 成果默认选择 report，不再错误选择数组尾；接受/要求修改和 Markdown 下载。
- 运行中轮询，阶段边界暂停，确认取消；失败重试/恢复和会话缓存保留明确旧版入口。
- 中文/英文、明暗主题与偏好持久化；认证失效清空私有页面投影。
- 模型 Markdown 不自动加载远程图片；相对/API 路径和非 HTTP(S) 链接显示为文本，
  绝对 HTTP(S) 链接只在用户主动点击时打开。
- Vite 只改写来自其自身 Host 的 Origin；其他 Origin 保留，由后端拒绝。
  未放宽 FastAPI 的访问边界。

本轮没有新增任意 DAG 编辑器、Agent 消息发送、代码写入、Shell、部署、多租户、
设备配对、第三方应用连接或真实模型请求。

## 4. Astryx 采用方式

| 产品用途 | Astryx 基础 | 本地所有权 |
| --- | --- | --- |
| 命令、工具按钮 | Button 的 icon、tooltip、loading、disabled | `AppButton` |
| 输入与资源 | TextInput、TextArea、NumberInput、Selector、CheckboxInput | 项目表单约束、角色路由、快照 consent |
| 弹层 | 原生 Dialog、focus trap、Escape、焦点返回 | `AppDialog`，提交中禁止关闭 |
| 状态 | Badge | 领域状态翻译及低干扰色彩 |
| 主题与语言 | Theme、neutral、InternationalizationProvider、zh-CN catalog | 一套产品 Token 与持久偏好 |
| 输出 | Markdown | 拦截自动远程图片与非 HTTP(S) 链接 |
| 工作阶段和运行页 | 通用组件组合 | 原创任务/调用/成果信息架构，不套演示数据 |

新业务模块不直接导入 vendor。旧 React 摘要/Chat 源与模板保留作历史和参考，
不代表所有遗留文件已完成封装治理。来源和许可证见
[开源研究第 20 节](OPEN_SOURCE_RESEARCH.md)；版本保持 0.7.13，不随迁移升级。

## 5. 验证与回滚

- 开发入口：`http://127.0.0.1:5173/`；API 代理至本机 4180。
- FastAPI 仍从 `web/` 提供生产静态页面，本轮未替换。
- `frontend/scripts/verify-workbench.mjs` 只能在显式声明的全新隔离 fixture
  中运行，会创建项目/模型/任务及 FakeProvider Run。禁止指向正式数据。
- 真实账号、付费模型、上游服务、Safari 和物理手机不是本轮验收范围。
- 类型、单测、构建、生产预览浏览器、主题/模板运行的最终结果记在
  [进度日志](PROGRESS_LOG.md)。构建警告与浏览器失败须保留，不以能编译代替可用。

## 6. 后续顺序

| 顺序 | 工作 | 验收门槛 |
| --- | --- | --- |
| 1 | React 原生重试与资源/继续运行 | 复用步骤、未知结果确认、稳定 request_id、新 Run lineage；不得覆盖历史 |

| 3 | 生产入口切换与性能预算 | API/静态资源同源部署、旧版回退、主流程等价、生产浏览器验证 |
| 4 | 固定流程的计划版本及资源可视化 | 编辑的是下一次草稿，不改已运行历史；之后再评估 DAG 编辑器 |
| 5 | 持续 Agent 与同一人多端接续 | 单事实源、设备授权/撤销、冲突/断线恢复；真实手机验收 |
| 6 | 应用与执行器扩展 | 飞书/钉钉/文档/邮件按 ConnectorPort 接入；微信能力及许可单独核验；Rust Node/GUI 按边界和性能证据决定 |

这些是实施顺序，不是已接入功能，也不以新增测试数减少原台账剩余项。
