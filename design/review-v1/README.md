# 原创图形化低保真 V1

状态：待评审的静态设计稿，不是业务应用或已通过的视觉基线。

直接打开 [index.html](index.html)，不需要启动服务。顶部下拉菜单切换设计画面；工作区内的链接可切换已绘制的关联画面。

## 范围

- 工作台、项目与任务。
- 任务依赖和 Agent 委派两个不同视图。
- 调用时间线、调用片段和失败尝试详情。
- 代码变更、验证证据与审计。
- 独立的审批、结果未知快照。

## 设计与数据边界

所有内容均为示例，页面持续显示“静态设计”标记。模型 A/B 不是已配置的真实模型；命令、Diff、Token 和时间均不是实际运行结果。

Run 02 表达失败后的工作流；审批是修复后的 Run 03 独立快照；结果未知是 Run 04 独立快照，不是点击审批后真的执行了动作。

模型连接、发起运行、授权、写入、提交和重试等业务操作禁用。交互只用于设计审阅、查看静态详情和切换画面；没有网络请求、凭证存储或执行后端。

不继承旧 `prototype/`、本地项目或上游项目的界面。本目录使用少量本地 Lucide 图标，不需要 CDN。

## 验证

`verify.mjs` 使用 Playwright 和独立浏览器进行静态渲染检查，不运行模型或工具任务：

```bash
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs \
CHROME_PATH=/path/to/chrome \
node design/review-v1/verify.mjs
```

若当前环境已经可直接导入 `playwright`，可省略 `PLAYWRIGHT_MODULE`。

脚本检查 18 个画面在 6 个视口下的全页水平溢出、图标、主要内容与控件截断，并检查部分画面导航、手机图的列表替代、导航焦点恢复和业务动作禁用。

结果在 `evidence/verification.json`，选定截图在 `evidence/screenshots/`。检查通过不等于用户体验、视觉或可访问性已经全部验收；它也不能证明真实 Agent 调度、安全隔离和恢复能力。
